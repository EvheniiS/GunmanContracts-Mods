# Fire Selector

Tested: 1.2.3 (2026-10-05)

Part of [Gunman Contracts Mods](../README.md). Hold A / X on the support hand to switch automatic guns between automatic, 3-round burst (optional, `AllowBurst`) and single shot. Flat (desktop) mode since 1.2.0: **B** cycles the same modes (`FlatKey`). 1.2.3 was played in flat only (auto, single, burst OK);
the VR selector was last played on 1.1.0, and 1.2.x skips flat-backed guns in the VR path, so give VR a quick check before release. Page text: `release/FireSelector/NEXUS_DESCRIPTION.txt`.
