[size=5][b]Better Bow[/b][/size]

The bow in Gunman Contracts, fixed and expanded: a [b]quiver on your shoulder[/b], an arrow you can
[b]stab with[/b] or [b]throw with aim assist[/b], a string that grabs on the [b]first[/b] press, arrows that
[b]blow up barrels[/b] and [b]breach doors[/b]. Everything is optional and can be switched off on its own.

[size=4][b]Features[/b][/size]
[list]
[*][b]Quiver.[/b] Holster the bow on a shoulder and take it in one hand. Reach back to that
shoulder with the other hand and press grip: you draw an arrow. Bring it to the string to nock
it. The quiver is wherever the bow was holstered, so the other shoulder stays free for a rifle
or shotgun. It works with either hand. Taking an arrow straight from the string still works too.
[*][b]Dagger grip.[/b] Holding a drawn arrow, press [b]A[/b] (right hand) or [b]X[/b] (left hand) to
flip it into a knife grip: the shaft runs along your knuckles, tip pointing down (or up, if
you prefer: DaggerTip). Press again to switch back.
A held arrow stabs enemies either way.
[*][b]Throw assist.[/b] Throw a drawn arrow like a throwing knife and it gets the game's own knife
aim assist: it homes in on the enemy you are looking at and hits for full damage. It follows
the game's [i]Assisted Throw[/i] option, so turn that on in the game settings. An enemy wearing a
vest is aimed at the head, since an arrow in armour does next to nothing.
[*][b]String grab on the first press.[/b] When shooting fast you often had to press grip twice
to get the next arrow. The game only grabs on the exact frame you press grip, and while grip is
held the hand can't pick up anything new, so a press a moment early was thrown away. Better Bow
completes that grab through the game's own grab code (15 cm around the string).
Tested: 55 of 55 fast draws on the first press.
[*][b]Explosive barrels:[/b] one arrow detonates them. Arrows hit with raw damage (100) while a
barrel has 250 health, so it took three. Knives, bullets and other objects are unchanged.
[*][b]Doors:[/b] shooting an arrow at a door's "shoot here to burst open door" mark breaches it,
exactly like a pistol shot (same range). Before, only guns could do it.
[/list]

Arrow counts, ammo and scoring are untouched: every arrow still goes through the game's own
bow code.

[size=4][b]Install[/b][/size]
Takes about 5 minutes the first time. Steps 1 and 2 are needed only once, for all MelonLoader mods.

[b]Where is my game folder?[/b] In Steam, right-click [i]Gunman Contracts - Stand Alone[/i] →
[i]Manage[/i] → [i]Browse local files[/i]. It's the folder with [i]GunmanContracts.exe[/i] in it.

[b]1. Install MelonLoader[/b] (the mod loader)
Download the installer from [url=https://github.com/LavaGang/MelonLoader/releases]MelonLoader releases[/url],
run it, pick [i]GunmanContracts.exe[/i] in your game folder, and install [b]version 0.7.3 or newer[/b].
[b]Version 0.6 does not work[/b] with this game.

[b]2. Start the game once[/b], then quit.
A black console window opens next to the game: that's MelonLoader working. The first start takes
a minute or two, later ones are normal.

[b]3. Add the mod[/b]
Open the downloaded zip. Inside is a folder called [b]Mods[/b]. Drag that [b]Mods[/b] folder into your
game folder, and if Windows asks, choose to replace / merge.
You should end up with: [i]Gunman Contracts - Stand Alone\Mods\BetterBow.dll[/i]
[b]Updating from Arrow Grab Assist or Arrow Quiver?[/b] Delete those DLLs from [i]Mods[/i]: Better Bow
contains both.

[b]4. Check it works[/b]
Start the game. The MelonLoader console lists [b]Better Bow v1.1.0[/b] among the loaded mods.

[b]Not working?[/b]
[list]
[*][b]The mod isn't in the console list:[/b] check the file isn't at [i]Mods\Mods\BetterBow.dll[/i] (a folder
too deep). Move it up so it sits directly in [i]Mods[/i].
[*][b]No console window at all:[/b] MelonLoader isn't installed on this game. Repeat step 1 and make
sure you picked [i]GunmanContracts.exe[/i].
[*][b]Errors right at startup:[/b] you likely have MelonLoader 0.6. Install 0.7.3 or newer.
[/list]

[size=4][b]Settings (optional)[/b][/size]
[spoiler]
After the first launch, edit [i]UserData\MelonPreferences.cfg[/i], section [b][BetterBow][/b]:
[code]
StringGrabAssist               = true   the first-press string grab
StringGrabRadius               = 0.15   metres from hand to string
ExplosiveArrowsDetonateBarrels = true   one arrow detonates an explosive barrel
ArrowsBreachDoors              = true   arrows open "shoot here" doors
Quiver                         = true   draw arrows from the bow's holster
QuiverRadius                   = 0.20   how close to the holster the hand must be
NockRadius                     = 0.15   how close to the string a carried arrow nocks
DroppedArrowLifetime           = 10     seconds before a dropped arrow disappears
HapticOnDraw                   = true   short buzz when you draw
GripSwitch                     = true   A / X switches to the dagger grip
DaggerGripFromNock             = 0.25   where on the shaft the dagger grip holds
DaggerTip                      = Down   dagger grip tip points Down or Up
ThrowAssist                    = true   thrown arrows get the knife aim assist
ThrowAssistSpeed               = 0      homing speed in m/s (0 = same as the game's knives)
ThrowAssistAvoidVest           = true   aim at the head of an enemy wearing a vest
ThrowStabReach / ThrowStabBack = 0.5 / 0.3   how far the hit check looks ahead of / behind the tip
HandsKeepParentAfterPause      = true   safety net for hands stuck after a pause
PhoneSettingsRescue            = true   safety net for a stuck phone Settings button
DebugLog                       = false  log everything to the MelonLoader console
[/code]
[/spoiler]

[size=4][b]Changelog[/b][/size]
[spoiler]
[b]1.1.0[/b]
[list]
[*][b]New: throw assist[/b] for drawn arrows (see Features).
[*][b]Fixed: the phone's Settings button stopped working and your hands drifted away when
moving with the stick[/b] after using the dagger grip. The grip copied a hidden wrist display
along with the arrow's hand pose, which took the place of your real one, and the pause menu
then failed halfway. If you saw either problem with 1.0.0, this was the cause.
[*][b]Fixed: DaggerTip = Down pointed the tip up.[/b] Down now points down. If you had switched to
Up to get a downward tip, switch back to Down. The old DaggerOrientation line in the settings
file is no longer used and can be deleted.
[/list]
[b]1.0.0[/b]: first release (Arrow Grab Assist and Arrow Quiver combined).
[/spoiler]

[size=4][b]Compatibility[/b][/size]
Works alongside my other Gunman Contracts mods, Fire Selector (fire modes for automatic weapons)
and Knee Shot Stun (leg-shot enemies stay down longer). The dagger grip uses A / X only while that
hand holds an arrow, so it never clashes with Fire Selector.

[size=4][b]Uninstall[/b][/size]
Delete [i]Mods\BetterBow.dll[/i].
