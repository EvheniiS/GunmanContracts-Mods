[size=5][b]Mod Settings[/b][/size]

Mod Settings shows [b]MelonPreferences settings[/b] from your installed mods on an [b]in-VR board[/b].
Open it from the [b]phone tile[/b] or with Ctrl+M, then touch the controls with your index finger.

[size=4][b]How to use[/b][/size]
Take out the phone and press the Mod Settings tile in the middle row. Ctrl+M on the keyboard also
opens or closes the board. It appears in front of you and follows you when you move with the stick.
Touch the buttons from the front with either index fingertip.
[list]
[*][b]< / >[/b] at the top switches between mods. [b]Up / Down[/b] scrolls through a mod's settings.
[*]Touch a setting's name to see its description and default value. [b]Reset[/b] restores that default.
[*]Tap [b]ON / OFF[/b] to change a switch. Numbers have small and large step buttons on either side.
Choices and colours use [b]< / >[/b].
[*]Some values, including keys, paths and holster positions, are read-only here. Edit those in
[i]MelonPreferences.cfg[/i].
[*]A yellow name means the value differs from its default. [b]*[/b] means the setting's description
says it needs a game restart.
[/list]

[size=4][b]When changes apply[/b][/size]
Changes are saved to [i]MelonPreferences.cfg[/i] about a second after you make them. Some mods use
the new value right away. Others read it only when a level loads or the game starts, so you may
need to reload or restart. The [b]*[/b] marker appears when the mod's own setting description says
to restart.

Each mod still decides how it uses its settings. Mod Settings only reads and changes their
MelonPreferences entries.

[size=4][b]Install[/b][/size]
Takes about 5 minutes the first time. Steps 1 and 2 are needed only once, for all MelonLoader mods.

[b]Where is my game folder?[/b] In Steam, right-click [i]Gunman Contracts - Stand Alone[/i] →
[i]Manage[/i] → [i]Browse local files[/i]. It's the folder with [i]GunmanContracts.exe[/i] in it.

[b]1. Install MelonLoader[/b] (the mod loader)
Download the installer from [url=https://github.com/LavaGang/MelonLoader/releases]MelonLoader releases[/url],
run it, pick [i]GunmanContracts.exe[/i] in your game folder, and install [b]version 0.7.3 or newer[/b].
[b]Version 0.6 does not work[/b] with this game.

[b]2. Start the game once[/b], then quit.
A black console window opens next to the game: that's MelonLoader working. The first start takes
a minute or two, later ones are normal.

[b]3. Add the mod[/b]
Open the downloaded zip. Inside is a folder called [b]Mods[/b]. Drag that [b]Mods[/b] folder into your
game folder, and if Windows asks, choose to replace / merge.
You should end up with: [i]Gunman Contracts - Stand Alone\Mods\ModSettings.dll[/i]

[b]4. Check it works[/b]
Start the game. The MelonLoader console lists [b]Mod Settings v0.2.2[/b] among the loaded mods.

[b]Not working?[/b]
[list]
[*][b]The mod isn't in the console list:[/b] check the file isn't at [i]Mods\Mods\ModSettings.dll[/i]
(a folder too deep). Move it up so it sits directly in [i]Mods[/i].
[*][b]No console window at all:[/b] MelonLoader isn't installed on this game. Repeat step 1 and make
sure you picked [i]GunmanContracts.exe[/i].
[*][b]Errors right at startup:[/b] you likely have MelonLoader 0.6. Install 0.7.3 or newer.
[*][b]No tile on the phone:[/b] the middle-row slot is sometimes held by a mission item (e.g. a
Data Breach holder); the tile moves to the next empty slot while that's active. Ctrl+M always
works regardless.
[/list]

[size=4][b]Settings (optional)[/b][/size]
[spoiler]
After the first launch, edit [i]UserData\MelonPreferences.cfg[/i], section [b][ModSettings][/b]:
[code]
PhoneTile   = true   put a Mod Settings tile in an empty slot of the phone's middle row
OpenKey     = M       keyboard: Ctrl + this key opens/closes the menu
PanelDistance = 0.4   how far in front of your eyes the menu opens, in metres
PanelScale  = 1        menu size (1 = 48 x 44 cm); applies the next time it opens
DebugLog    = false   log opening/closing and write the phone layout to UserData\ModSettings_phone.txt once
[/code]
Mod Settings does not show its own options on the board; edit these in the cfg.
[/spoiler]

[size=4][b]Compatibility[/b][/size]
Works alongside [url=https://www.nexusmods.com/gunmancontractsstandalone/mods/22]Better Bow[/url],
[url=https://www.nexusmods.com/gunmancontractsstandalone/mods/25]Fire Selector[/url],
[url=https://www.nexusmods.com/gunmancontractsstandalone/mods/26]Knee Shot Stun[/url] and
[url=https://github.com/EvheniiS/GunmanContracts-Mods]Heavy Melee[/url]. Mod Settings uses its
own phone tile and Ctrl+M, so it does not take over those mods' controls. Other mods that use
MelonPreferences should appear on the board too; hidden settings are not shown.

[size=4][b]Uninstall[/b][/size]
Delete [i]Mods\ModSettings.dll[/i]. Your cfg keeps whatever values were last saved.
