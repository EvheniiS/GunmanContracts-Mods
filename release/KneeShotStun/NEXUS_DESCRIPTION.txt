[size=5][b]Knee Shot Stun[/b][/size]

Shoot an enemy in the leg and they [b]go down on one knee and stay there[/b], long enough to
actually use it: close the distance, take a second target, or line up the finishing shot.

[size=4][b]What it does[/b][/size]
In the game, a leg shot drops an enemy to one knee for only about [b]0.65 seconds[/b] before they
get back up. With this mod they stay on the knee [b]3 seconds longer[/b] (you can change it).
[list]
[*]Only the kneeling part is lengthened. The fall and the getting-up play at normal speed, so it
looks like the game's own animation, not a freeze.
[*]The enemy stays [b]stunned[/b] for the whole time on the knee, just like during the game's own
short kneel, and until they are back on their feet.
[*]Shooting a kneeling enemy in the leg again doesn't cut the stun short.
[*]Kill them while they're down and they die with the game's [b]kneeling death[/b] animation, the
same as during the original kneel.
[/list]

Nothing else about enemies, damage or scoring is changed.

[size=4][b]Install[/b][/size]
Takes about 5 minutes the first time. Steps 1 and 2 are needed only once, for all MelonLoader mods.

[b]Where is my game folder?[/b] In Steam, right-click [i]Gunman Contracts - Stand Alone[/i] →
[i]Manage[/i] → [i]Browse local files[/i]. It's the folder with [i]GunmanContracts.exe[/i] in it.

[b]1. Install MelonLoader[/b] (the mod loader)
Download the installer from [url=https://github.com/LavaGang/MelonLoader/releases]MelonLoader releases[/url],
run it, pick [i]GunmanContracts.exe[/i] in your game folder, and install [b]version 0.7.3 or newer[/b].
[b]Version 0.6 does not work[/b] with this game.

[b]2. Start the game once[/b], then quit.
A black console window opens next to the game: that's MelonLoader working. The first start takes
a minute or two, later ones are normal.

[b]3. Add the mod[/b]
Open the downloaded zip. Inside is a folder called [b]Mods[/b]. Drag that [b]Mods[/b] folder into your
game folder, and if Windows asks, choose to replace / merge.
You should end up with: [i]Gunman Contracts - Stand Alone\Mods\KneeShotStun.dll[/i]

[b]4. Check it works[/b]
Start the game. The MelonLoader console lists [b]Knee Shot Stun v1.0.0[/b] among the loaded mods.

[b]Not working?[/b]
[list]
[*][b]The mod isn't in the console list:[/b] check the file isn't at [i]Mods\Mods\KneeShotStun.dll[/i] (a folder
too deep). Move it up so it sits directly in [i]Mods[/i].
[*][b]No console window at all:[/b] MelonLoader isn't installed on this game. Repeat step 1 and make
sure you picked [i]GunmanContracts.exe[/i].
[*][b]Errors right at startup:[/b] you likely have MelonLoader 0.6. Install 0.7.3 or newer.
[/list]

[size=4][b]Settings (optional)[/b][/size]
[spoiler]
After the first launch, edit [i]UserData\MelonPreferences.cfg[/i], section [b][KneeShotStun][/b]:
[code]
Enabled           = true   leg-shot enemies stay down longer
ExtraKneelSeconds = 3.0    seconds added to the kneel (the game's own kneel is about 0.65 s)
DebugLog          = false  log each knee shot to the MelonLoader console
[/code]
[/spoiler]

[size=4][b]Compatibility[/b][/size]
Works alongside my other mods ([url=https://www.nexusmods.com/gunmancontractsstandalone/mods/22]Better Bow[/url],
Fire Selector) and should work with any mod that doesn't change the enemies' hit animations.

[size=4][b]Uninstall[/b][/size]
Delete [i]Mods\KneeShotStun.dll[/i].
