# Daredevil — Nexus requirements draft

## Required companion mods

- Gloves
- Throw Assist
- Mod Settings

These are the required companions listed in the current Daredevil README. Daredevil itself still loads without them and logs missing companions.

## Optional but highly recommended

- **Heavy Melee**
- **Physical Dodge**
- **Enemy Awareness Fix**

List all three as optional on Nexus, with “Optional but highly recommended for the Daredevil experience” in each requirement note. None is a hard dependency.

## Other optional integration

- **Weapon Framework** — adds the billy clubs to the arsenal panel in The Range.

## Artwork copy

- Title: **DAREDEVIL** — DARE in game-yellow; DEVIL in red.
- Game label: **GUNMAN CONTRACTS**
- Thumbnail feature line: **BILLY CLUBS / RADAR SENSE**

The visuals feature the paired clubs and radar silhouettes from the supplied gameplay screenshot. Requirements belong in the listing text rather than the artwork.
