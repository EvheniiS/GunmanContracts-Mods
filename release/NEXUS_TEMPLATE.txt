# Nexus description template

Skeleton for `release/<Mod>/NEXUS_DESCRIPTION.txt`, extracted from the four published pages
(Better Bow, Fire Selector, Knee Shot Stun, Heavy Melee). Copy the BBCode block below, fill in
the `{{...}}` placeholders, and drop or rename the free-form section(s) in the middle to fit the
mod. The Install / Settings / Compatibility / Uninstall / Source sections are boilerplate shared
by every mod so far — keep them word-for-word except the placeholders, so a returning reader
always knows where to find the same information.

**Rules learned from the existing pages, worth keeping:**
- Tagline bolds the 3-4 things the mod actually changes; nothing else in the opening paragraph is bold.
- One free-form section per distinct thing the mod does, `[size=4][b]...[/b][/size]` named for
  what's in it ("What it does", "How to use", "Grabbing still works", "Also fixed") rather than
  forced into a generic "Features" every time.
- A short closing line naming what's untouched/vanilla ("Arrow counts... untouched", "Shooting
  itself is the game's own code") reassures a wary modder and has appeared in every page so far —
  include one if it's true.
- Settings block lists every `MelonPreferences` entry with an inline one-line comment, values
  exactly as they ship (copy from the mod's `Cfg`/`Settings` class, don't retype from memory).
- Compatibility names the other released mods by their actual conflicts (shared buttons, shared
  hooks), not just "works fine together" — say *why* if there's a shared input or system.
- Changelog is a spoiler, newest version first, only added once there's a second version; each
  entry is `[b]New:[/b]` / `[b]Fixed:[/b]` items, not prose paragraphs.
- Version number appears in exactly one place outside the changelog: the "Check it works" line
  in Install. Don't also hardcode it in the tagline or Features.

[size=4][b]Install[/b][/size]
Takes about 5 minutes the first time. Steps 1 and 2 are needed only once, for all MelonLoader mods.

[b]Where is my game folder?[/b] In Steam, right-click [i]Gunman Contracts - Stand Alone[/i] →
[i]Manage[/i] → [i]Browse local files[/i]. It's the folder with [i]GunmanContracts.exe[/i] in it.

[b]1. Install MelonLoader[/b] (the mod loader)
Download the installer from [url=https://github.com/LavaGang/MelonLoader/releases]MelonLoader releases[/url],
run it, pick [i]GunmanContracts.exe[/i] in your game folder, and install [b]version 0.7.3 or newer[/b].
[b]Version 0.6 does not work[/b] with this game.

[b]2. Start the game once[/b], then quit.
A black console window opens next to the game: that's MelonLoader working. The first start takes
a minute or two, later ones are normal.

[b]3. Add the mod[/b]
Open the downloaded zip. Inside is a folder called [b]Mods[/b]. Drag that [b]Mods[/b] folder into your
game folder, and if Windows asks, choose to replace / merge.
You should end up with: [i]Gunman Contracts - Stand Alone\Mods\{{Mod}}.dll[/i]
{{Optional: "Updating from X or Y?" migration note, e.g. Better Bow superseding two older mods.}}

[b]4. Check it works[/b]
Start the game. The MelonLoader console lists [b]{{Mod Name}} v{{X.Y.Z}}[/b] among the loaded mods.

[b]Not working?[/b]
[list]
[*][b]The mod isn't in the console list:[/b] check the file isn't at [i]Mods\Mods\{{Mod}}.dll[/i] (a folder
too deep). Move it up so it sits directly in [i]Mods[/i].
[*][b]No console window at all:[/b] MelonLoader isn't installed on this game. Repeat step 1 and make
sure you picked [i]GunmanContracts.exe[/i].
[*][b]Errors right at startup:[/b] you likely have MelonLoader 0.6. Install 0.7.3 or newer.
[/list]
