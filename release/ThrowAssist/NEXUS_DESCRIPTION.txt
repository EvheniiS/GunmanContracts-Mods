[size=5][b]Throw Assist[/b][/size]

Steers assisted throws with [b]real physics[/b] instead of dragging items to their targets. It enables
[b]assisted pistol throws[/b] (disabled in the base game), adds [b]thrown-pistol damage and stagger[/b], and lets
throws aim for [b]headshots based on your release direction[/b].

[size=4][b]What it does[/b][/size]
[list]
[*][b]Physical flight:[/b] the game's Assisted Throw option picks an enemy, but normally drags the item to it
with [i]MovePosition[/i], zeroing its velocity and spin. This mod steers with real velocity instead, preserving
spin and collisions along the way. Turn on the game's [b]Assisted Throw[/b] option for targeting to work.
[*][b]Pistols:[/b] every pistol ships with its throw assist switched off. This mod turns it on for throws
faster than [i]PistolAssistMinSpeed[/i] and the game's own threshold. A thrown pistol that lands on an enemy does real damage (torso x2, head x5,
a head hit kills) and staggers them — the game's own thrown-pistol hit does neither.
[*][b]Headshot option:[/b] [i]AimHead[/i] is on for new installs. When your release points closer to the head
than the chest and within the configurable angle, the assist aims at the head; otherwise it aims at the chest.
This follows your throw direction, not a random headshot chance. Set [i]AimHead = false[/i] for chest-only aim.
[*][b]Knives:[/b] with [i]SteerOtherItems[/i] on (the default for new installs), assisted throws fly at the
knife's own game assist speed (17 m/s on the tested combat knife)
or faster, blade first. The earlier test recorded 14 stabs in 14 assisted throws; face bounces still need more
testing. Throws without an assist target can tumble end over end in the throw's vertical plane. [i]SteerOtherItems[/i]
also enables eligible props, though knife throwing is the focus and other props have not been broadly tested.
[/list]

[size=4][b]Experimental knee assist[/b][/size]
Version 0.2.2 includes optional knee
targeting and a kneel reaction on thrown-item leg hits. It uses the same knee-shot animation as Billy Clubs;
Knee Shot Stun can extend the kneel. The setting
[i]allowKneeHit[/i] defaults to [b]false[/b]. Knee targeting and leg contacts still need tuning: a throw
aimed toward the knee can contact another part of the leg, and a kneel is not guaranteed.

[size=4][b]Billy Clubs[/b][/size]
If [url=https://github.com/EvheniiS/GunmanContracts-Mods][b]Daredevil[/b][/url] is installed, its billy clubs
fly their own ricochet/spin-style flight and this mod steps aside for them — the two never steer the same throw.

Shooting, melee and everything else about the guns and knives themselves is the game's own code.

[size=4][b]Install[/b][/size]
Takes about 5 minutes the first time. Steps 1 and 2 are needed only once, for all MelonLoader mods.

[b]Where is my game folder?[/b] In Steam, right-click [i]Gunman Contracts - Stand Alone[/i] →
[i]Manage[/i] → [i]Browse local files[/i]. It's the folder with [i]GunmanContracts.exe[/i] in it.

[b]1. Install MelonLoader[/b] (the mod loader)
Download the installer from [url=https://github.com/LavaGang/MelonLoader/releases]MelonLoader releases[/url],
run it, pick [i]GunmanContracts.exe[/i] in your game folder, and install [b]version 0.7.3 or newer[/b].
[b]Version 0.6 does not work[/b] with this game.

[b]2. Start the game once[/b], then quit.
A black console window opens next to the game: that's MelonLoader working. The first start takes
a minute or two, later ones are normal.

[b]3. Add the mod[/b]
Open the downloaded zip. Inside is a folder called [b]Mods[/b]. Drag that [b]Mods[/b] folder into your
game folder, and if Windows asks, choose to replace / merge.
You should end up with: [i]Gunman Contracts - Stand Alone\Mods\ThrowAssist.dll[/i]
Turn on the game's own [b]Assisted Throw[/b] option in its settings, or this mod has nothing to steer.

[b]4. Check it works[/b]
Start the game. The MelonLoader console lists [b]Throw Assist v0.2.2[/b] among the loaded mods.

[b]Not working?[/b]
[list]
[*][b]The mod isn't in the console list:[/b] check the file isn't at [i]Mods\Mods\ThrowAssist.dll[/i] (a folder
too deep). Move it up so it sits directly in [i]Mods[/i].
[*][b]No console window at all:[/b] MelonLoader isn't installed on this game. Repeat step 1 and make
sure you picked [i]GunmanContracts.exe[/i].
[*][b]Errors right at startup:[/b] you likely have MelonLoader 0.6. Install 0.7.3 or newer.
[*][b]Thrown items don't home in:[/b] turn on the game's own Assisted Throw option; a soft toss below
[i]MinAssistSpeed[/i] is left alone on purpose.
[/list]

[size=4][b]Settings (optional)[/b][/size]
[spoiler]
After the first launch, edit [i]UserData\MelonPreferences.cfg[/i], section [b][ThrowAssist][/b]:
[code]
PistolAssist       = true    Thrown pistols home in on enemies. The game ships its pistol assist switched off. Needs the game's own assisted throw option on.
SteerOtherItems    = true    Steer knives and other eligible items with real velocity. Billy Clubs use Daredevil's own flight.
MinAssistSpeed     = 3.5     Non-pistol props slower than this (m/s) get no assist. Knives use the game's own 3.5 m/s threshold.
PistolAssistMinSpeed = 3.5  Pistols slower than this or the game's threshold get no assist.
PistolSteerMinSpeed = 13   Minimum flight speed after a pistol acquires an assist target; unassisted throws are unchanged.
MaxSpeed           = 18      An assisted item flies at your own throw speed, up to this (m/s).
KnifeSpeedMultiplier = 1    1 uses each knife's own game assist speed as a floor; increase only after checking impact logs.
KnifeVerticalSpin  = true    A knife with no assist target tumbles end over end rather than spinning flat. False keeps its original spin.
SearchDistance     = 15      How far the assist looks for a target (m). Pistols as shipped: 6.
MaxFlyDistance     = 20      How far an assisted throw flies before it gives up (m). Pistols as shipped: 4.
AimHead            = true    Allow head assist only when the release points closer to the head than chest; false always aims at chest.
HeadAimMaxAngle    = 25      Maximum angle in degrees from release direction to head. Lower = stricter head aim.
PistolDamage       = true    A thrown pistol that hits an enemy does real damage (PistolThrowDamage). Off = the game's weak hit.
PistolThrowDamage  = 3       Thrown pistol damage as a multiple of the game's melee damage (10). The game then doubles it on the torso and multiplies by 5 on the head: 3 = 60 to the body, a head hit kills.
PistolStagger      = true    A thrown pistol that hits a standing enemy makes them stumble.
DebugLog           = true    Record releases, targets, knife impacts and stabs, and pistol hits in MelonLoader/Latest.log. Turn off after testing if desired.
[/code]
If you are upgrading, existing saved settings keep their previous values. Set [i]SteerOtherItems = true[/i] and
[i]AimHead = true[/i] explicitly if you want these new defaults. Set [i]AimHead = false[/i] at any time for chest aim.
Headshots are based on throw direction, not random chance: the release must point closer to the head than chest
and within [i]HeadAimMaxAngle[/i] of the head. Normal Daredevil club throws follow this rule too; ricochets have
their own [i]RicochetAimHead[/i] setting.
Knife and pistol release speed comes from the game's recent hand motion. Only Daredevil's Billy Clubs have the
separate short follow-through that can add speed from hand movement after release.
Or change these live in-VR with [url=https://www.nexusmods.com/gunmancontractsstandalone/mods/28][b]Mod Settings[/b][/url] (optional) — no restart, no text editor.
[/spoiler]

[size=4][b]Compatibility[/b][/size]
Required by [url=https://github.com/EvheniiS/GunmanContracts-Mods][b]Daredevil[/b][/url] — this mod
deliberately leaves any object named [i]BillyClub-*[/i] to Daredevil's own throw system. Heavy Melee only
affects [i]held[/i] guns, so there's no overlap with this mod's thrown-pistol damage.

[size=4][b]Uninstall[/b][/size]
Delete [i]Mods\ThrowAssist.dll[/i]. Thrown items go back to the game's own drag-and-zero-velocity assist.
