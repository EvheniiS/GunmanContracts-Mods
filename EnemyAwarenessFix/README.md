# Stealth AI Fix

Tested: 0.1.6

Part of [Gunman Contracts Mods](../README.md). Enemies that lose sight of you go to where they last saw you and search there instead of walking to your exact position. Wave enemies get a rough guess, wave spawns no longer always use the nearest spawn point, and hearing and "arrived" checks are floor-aware. Ships with the optional diagnostic [Enemy Awareness Log](../EnemyAwarenessLog/EnemyAwarenessLog.cs). Page text: `release/EnemyAwarenessFix/NEXUS_DESCRIPTION.txt`.
